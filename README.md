# 🚀 Featured Projects

## 🏥 HealthScan
### AI-Powered Pathology Intelligence Platform

HealthScan transforms unstructured pathology reports into structured, understandable insights using **OCR, NLP, LLMs and Retrieval-Augmented Generation**.

**Highlights**

- 📄 Extracts structured medical information from uploaded reports
- 🧠 Generates AI-powered clinical summaries and risk insights
- 🔎 Provides contextual Q&A through a **RAG-based chatbot**
- 📊 Tracks important biomarkers across reports
- 🔊 Generates multilingual AI audio summaries

**Tech Stack**

`Python` `FastAPI` `OCR` `NLP` `LLMs` `RAG` `Transformers` `MongoDB`
